# Windows 桌宠设计规格

## 目标

制作一个依据用户提供的三张照片重新绘制的 Windows 陪伴型桌宠。角色采用圆润 Q 版比例、黑色长发、柔和神态和浅色针织服装，保留服装上少量彩色装饰。桌宠在显示器可用区域底边活动，支持待机、走动、睡觉、点击回应和拖拽。交付可直接运行的 Windows x64 程序及源代码。

## 范围

第一版不含聊天、联网、提醒、喂食、成长、自动开机启动或多角色切换。照片只作为绘制参考，不作为运行时可见素材；程序运行时不读取原始照片。

## 技术与组件

- 使用 WPF 和 .NET 8 LTS 构建 Windows 桌面程序。发布为自包含 Windows x64 可执行文件，不要求用户单独安装 .NET。
- `PetWindow` 为透明、无边框、置顶且不显示任务栏按钮的小窗，仅角色可见区域响应鼠标。默认角色占用约 180 x 210 DIP，可按屏幕缩放保持清晰。
- `PetController` 管理待机、向左走、向右走、点击回应、睡觉和拖拽状态。状态转换只由计时器和用户操作驱动。
- `SpriteAnimator` 读取嵌入程序的透明帧素材，在固定尺寸画布内播放，避免动作间窗口尺寸跳变。
- `ScreenService` 查询当前显示器的工作区域，计算水平移动与底边位置；处理拖至其他显示器和显示器配置变化。
- `PreferencesStore` 将位置、活动暂停状态和手动睡眠状态保存到用户本地应用数据目录。损坏或过期的设置回退到安全默认值。
- 系统托盘与角色右键菜单提供“暂停/继续走动”“睡觉/唤醒”“退出”，角色被其他窗口遮挡时仍可通过托盘操作。退出时释放托盘图标和计时器。

## 角色与动画

先依据照片生成一张统一角色基准图，再以基准图制作各状态的透明帧。Q 版角色为完整身体；照片未展示清楚的下半身采用简洁的浅色下装与深色平底鞋，不假定这是照片中的实际穿着。角色脸型、发型、服装配色及彩色装饰在所有帧中保持一致。

- 待机：轻微呼吸、眨眼和发梢摆动，循环时不发生明显位移。
- 走动：左右朝向与交替步态；横向速度平缓，不附加飘散的特效。
- 点击回应：短暂微笑或挥手，结束后回到待机。
- 睡觉：闭眼和轻微呼吸；手动睡眠保持到唤醒，自动睡眠可由点击唤醒。
- 拖拽：暂停自主移动并使用稳定姿势；松开后对齐目标显示器工作区域的底边。

所有素材须有透明背景，无原照片背景、文字、水印或明显的边缘色晕。以实际桌宠显示尺寸检查角色可辨认度、帧间比例与脚底基线。

## 行为与输入

启动时恢复上次显示器与水平位置；找不到该显示器时放到主显示器工作区域底边。没有设置时默认在主显示器右侧、任务栏上方出现。

角色随机短距离左右走动，穿插待机；每次移动的目标点限制在当前显示器工作区域内。连续五分钟没有用户互动时进入自动睡眠。单击角色使其回应或唤醒；按住并移动超过拖拽阈值后进入拖拽，避免把单击误判为拖拽。拖到其他显示器后，以新显示器为活动范围。暂停走动时仍能点击、拖拽和手动睡觉。

工作区域和 DPI 在显示设置变化后重新计算。角色必须保持完整可见，不能走入任务栏或越过屏幕左右边界。右键打开菜单，不触发点击回应。

## 失败处理

素材解码失败时显示明确错误并正常退出，避免留下空白的置顶窗口。设置文件读取失败时使用默认设置并继续启动；写入失败不影响当次互动。托盘图标创建失败时仍保留角色右键退出入口。所有程序数据保留在用户本地，不上传照片或行为数据。

## 验收

- 在 Windows 上启动后出现透明角色窗口，没有矩形背景或多余任务栏按钮。
- 待机、双向走动、点击回应、睡觉与拖拽动作可见且角色外观一致。
- 角色在任务栏上方活动；拖拽换屏、边界和显示缩放行为正确。
- 右键和托盘控制有效；退出后进程、计时器与托盘图标消失。
- 重启后恢复合理的位置与暂停/手动睡眠状态；设置损坏时仍可启动。
- 自包含发布的程序在没有项目源码和开发 SDK 的环境下可以运行。

以状态转换、边界计算和设置读写的自动化测试覆盖关键逻辑；在实际桌面上检查透明度、动画连贯性、鼠标命中范围和托盘交互。若测试环境只有一个显示器，使用几何单元测试覆盖多显示器场景，并将实际双屏验证标为未实测。
