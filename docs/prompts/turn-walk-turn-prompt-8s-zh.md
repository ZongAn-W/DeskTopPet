# 组合动作 Prompt（中文 · 8 秒版）：右转 90° → 原地面朝右侧走几步 → 转回正面

面向桌宠的组合镜头中文提示词：**正面 → 右转 90° →（面朝画面右侧）原地走几步 → 转回正面**。
两次转身各 90°，且**每一步动作完全相同**（同一步幅、同一抬脚高度、同一节奏），
整体连续流畅。首尾帧都是同一张正面参考图，可直接无缝循环。

参考角色：3D Q 版女孩，黑色中分长发、柔和肤色、温柔微笑、灰色长大衣、
白色翻领衬衫、蓝色宽松牛仔裤、黑白运动鞋，头大身小的幼儿比例。

| 时间段 | 动作 |
| --- | --- |
| 0.00–1.00 s | 正面静止 |
| 1.00–2.00 s | 向右转 90°（面朝画面右侧，我们看到她的左侧） |
| 2.00–5.00 s | 面朝画面右侧原地行走，**三步，每步完全相同** |
| 5.00–6.00 s | 转回正面（反向 90°） |
| 6.00–8.00 s | 正面静止，与首帧一致 |

## 三、运动路径（时间轴 / 帧表）

| 时间段 | 动作 | 关键约束 |
| --- | --- | --- |
| 0.00–1.00 s | 正面静止 | 与参考图完全一致的正面站姿，完全静止 |
| 1.00–2.00 s | 向右转 90° | 视线/头先行，肩胸、腰胯、双腿依次跟随；原地轴转，不迈步、不位移 |
| 2.00–3.00 s | 第一步（面朝右） | 完整抬脚—迈步—落地—蹬地；步幅、抬脚高度、节奏 = 标准步 |
| 3.00–4.00 s | 第二步 | **与第一步逐帧一致**，仅左右镜像对称 |
| 4.00–5.00 s | 第三步 | **与第一步逐帧一致**，节奏均匀，无长短步 |
| 5.00–6.00 s | 转回正面 90° | 反向、速度与第一次转身相同；原地轴转，不迈步 |
| 6.00–8.00 s | 正面静止 | 与首帧逐像素一致，可无缝循环 |

**朝向判读（关键，容易弄反）**
- 面朝画面右侧时，我们看到的是**她的左侧**：左侧脸颊、左肩、左臂、左腿在前，鼻子指向画面右边缘。
- 第一次转身过程中画面宽度会由正面的全宽收窄到侧面的窄轮廓，这是正确现象；
  **画面高度必须基本不变**，**双脚脚底始终在同一水平基线上、原地不滑动**。
- 行走段的画面宽度保持侧面的窄轮廓，**不得**因为身体转动变宽成正面或 3/4 视角。

**帧率与时长**
- 输出 8 s / 30 fps 或更高（60 fps 更好，便于后续重采样）。
- 按桌宠现有 8 fps 采样：整段 64 帧；行走三步 = 24 帧，每步 8 帧，三步帧数完全相同，
  便于在动画表里直接复用同一组 8 帧循环三次。
- 2.00 s 处即为"面朝右侧"的静止姿势关键帧，可直接抽取作为行走用的右向素材。

**如果嫌 8 秒太长**
压缩到 6 秒：正面静止 0.5 s（0–0.5）、右转 1 s（0.5–1.5）、走三步 3 s（1.5–4.5）、
转回 1 s（4.5–5.5）、正面静止 0.5 s（5.5–6.0）。其余文字不用改。

## 四、交付规格与首尾帧检查

**交付要求**
- 视频 8 s，30 fps 或以上，无音轨。
- 分辨率不低于 1080 × 1080；角色整体不被裁切，头发、双手、大衣下摆、鞋底全部在画面内。
- 首帧必须与参考图一致，便于直接作为第 0 帧对齐。

**首尾帧检查**
1. 首帧与末帧逐项比对：正面朝向、双眼睁开、温柔微笑、双臂自然垂下、双脚同一水平基线，两者必须完全相同。
2. 核对头顶、肩膀、双手、大衣下摆、鞋底位置：整段过程中不得出现整体位移，行走时上下起伏必须极小。
3. 两次转身都必须是恰好 90 度：第一次结束时面朝画面右侧，第二次结束时精确回到正面。
4. 转场衔接处（1.00 / 2.00 / 5.00 / 6.00 s）不得有姿态跳变、抽帧或速度突变；
   转身结束到起步之间不允许出现"先走一步再转"或"转完停住不动"的断层。
5. **逐帧比对三步**：把三步各自的 8 帧（8 fps 采样）叠在一起比对，
   步幅、抬脚高度、膝盖弯曲角度、手臂摆动位置必须完全对应，不得有长短步或快慢步。
6. 行走段的朝向全程为面朝画面右侧的侧面轮廓，不得转成正面或 3/4 视角。
7. 双脚脚底基线全程不变，落地脚不滑动、不陷入、不悬空；每一步都是完整的抬脚—落地过程。
8. 镜头视角、透视、焦距、构图、角色占比全程一致。
9. 绿幕背景全程均匀纯绿，无光照变化、无阴影、无闪烁、无绿色溢色光晕。
10. 逐帧检查无运动模糊与残影；循环衔接处无位置跳动、无大小变化、无表情突变。

**落地到项目素材**
- 透明 PNG 序列，画布固定 180 × 210，脚底基线一致，底部留 2 px，水平居中。
- 命名连续无缺号放入 `src/DesktopPet/Assets/Character/`，重新构建即被资源打包。
- 建议这样拆分复用同一段视频：
  - `turn_right_000.png` 起：1.00–2.00 s（右转 90°）
  - `walk_right_000.png` 起：2.00–5.00 s（面朝右侧的三步；三步完全一致时，可只保留一个步态周期的 8 帧循环播放）
  - `turn_left_000.png` 起：5.00–6.00 s（转回正面）
- 注意：`SpriteAnimator` 的动画表当前为 `idle` / `walk_left` / `walk_right` / `respond` / `sleep` / `drag`，
  尚无 `turn_left` / `turn_right` 前缀，也尚无 Turn 状态——本轮只产出素材，接入需要另行扩展该表与状态机。

## 五、风险与备选

- **"每步一模一样"是这条提示词最容易失败的点**：模型倾向于让三步各有细微差别（步幅、节奏、手臂位置）。
  若一次生成达不到，最稳的做法是只生成**一个**步态周期（约 1 秒、8 帧），验收通过后在合成阶段
  复制三次构成三步，而不是指望模型每次都画得一致。
- **转身与起步的衔接**是第二个失败点：常见的错误是"转完先站一会儿再走"或"边走边转"。
  若出现，把 `转身是原地轴转，不迈步`、`转完立刻起步，之间不停顿` 提到提示词更靠前的位置。
- **行走时朝向漂移**：模型容易在走第二步、第三步时把侧脸转成 3/4 或正面。
  加强 `鼻子始终指向画面右边缘`、`全程保持侧面轮廓`，并在负面词中加强 `转成 3/4 视角, 朝向改变`。
- **整体位移**：若角色在 8 秒里缓慢漂出画面中心，抽帧后合入 180 × 210 画布时，
  用脚底基线与水平中心做统一锚点对齐即可抵消。
- 若 8 秒一条过不了，建议拆成三条分别验收：右转 90° / 面朝右侧走三步 / 转回正面，
  再在合成阶段拼接，避免把手部错误、朝向错误和步伐不齐混在同一条里排查。
